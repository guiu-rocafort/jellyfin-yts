YTS Torrents

Search YTS and send torrents to qBittorrent for download; finished movies are moved into the library folder below and a library scan is triggered automatically.

YTS

Default: https://yts.gg/api/v2 (fallback mirror: https://movies-api.accel.li/api/v2)

qBittorrent

e.g. http://qbittorrent:8080. Firewall this port to the Jellyfin host only — credentials below are stored unencrypted, the same way other Jellyfin plugins store third-party credentials.
A dedicated category is created in qBittorrent for torrents this plugin adds, so it can tell them apart from your other torrents.
Where qBittorrent downloads files to before they're imported. Must NOT be inside a Jellyfin library folder, so partially-downloaded files are never scanned.

Library

Finished movies are placed here as "Title (Year)/" folders, matching Jellyfin's standard naming convention.
Downloaded files are only removed from disk if the import mode is Move (Hardlink/Copy leave the qBittorrent copy alone).
